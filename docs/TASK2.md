# 第二轮修改：百分比呈现与画面层次

在第一轮（`docs/TASK.md`）的基础上修改。字体系统、颜色含义、数据、文字和交互都不变，`AGENTS.md` 的规则继续适用。

本轮只做三件事：

1. 数字改成以百分比为主；
2. 给画面加层次：插图、两种光、章节大字；
3. 在资料与说明里补充两行说明。

---

## 1. 数字改为以百分比为主

### 1.1 原则

- 大数字显示**整数百分比**，例如 `91%`。`%` 的字号是主数字的 45%。去掉"/23 人"这种分数写法。
- 每个百分比旁边或所在的图注里，都要能看到基数，例如"23人作答""用过AI倾诉的21人作答"。基数不能省。
- 条形图的条末标注改为 `62%`；分段条的段内标注改为 `30%`（宽度不够就不标）。提示框仍显示人数："13人，占62%（n=21）"。
- 百分比一律 `Math.round` 取整。
- 以下几处保留文字写法，不换成百分比：
  - 数量为 0 时写"没有人选择……"；
  - 第9屏的"11条回答中，4条提到情感……"和"另外2位没用过AI倾诉的同学，都认为……"（第12题只有2人，不能用百分比）；
  - 第12屏资料与说明里的样本量和年级构成。
- 第10题仍显示均分（如 2.62），不变。

## 2. 画面层次

现在每一屏都是同一种平涂背景、同一种两栏排版，看久了很单调。按"远、中、近"三层来加层次：

| 层 | 是什么 | 用在哪里 |
| --- | --- | --- |
| 远景 | 木刻版画风格的插图（小组用AI生成，放在 `img/`） | 第1、8、10、11屏 |
| 中景 | "两种光"：屏幕的青光和灯光、日光的琥珀光 | 所有深色屏 |
| 近景 | 章节大字：每一层第一屏的超大中文序号 | 第3、4、5、10屏 |

### 2.1 远景：插图

图片由小组另外生成，文件放在 `img/` 文件夹。**如果某张图还不存在，页面必须照常显示**：只是没有图，不能报错，也不能出现破图图标。用 CSS `background-image` 实现，不要用 `<img>`。

| 文件 | 屏 | 画面主体位置 | 放置方式 |
| --- | --- | --- | --- |
| `img/01-night.webp` | 第1屏 `#open` | 右侧三分之一（手机的青光） | 满版，`cover`，`background-position: right center`；聊天窗口叠在青光附近 |
| `img/02-windows.webp` | 第8屏 `#principle` | 整幅（一扇扇亮灯的窗） | 满版，非常淡，作为关系示意图背后的氛围 |
| `img/03-dawn.webp` | 第10屏 `#layer4` | 右上方（晨光照进窗） | 满版，替换现在顶部从夜到昼的渐变，图片本身就是"天亮" |
| `img/04-together.webp` | 第11屏 `#end` | 下方三分之一（并肩的背影） | 满版，`background-position: center bottom`；内容整体略上移，不要压住人物 |

**遮罩**：每张图上面叠一层与背景同色的渐变遮罩，保证文字对比度不低于 4.5:1。

- 深色屏（第1、8屏）：遮罩用该屏背景色。文字一侧不透明度 0.88，主体一侧 0.35。第8屏整体不低于 0.8，让关系示意图保持清楚。
- 浅色屏（第10、11屏）：遮罩用 `#ECECE6`。文字一侧不透明度 0.9，主体一侧 0.3。
- 遮罩方向跟随文字位置：文字在左，就从左到右渐变。

图片不做视差、不做缩放动画。进入该屏时可以有一次 0.8 秒的淡入（`prefers-reduced-motion` 时直接显示）。

### 2.2 中景：两种光

整个作品讲的是两种光：深夜手机屏幕的**青光**（AI），台灯和日光的**琥珀光**（人）。用两种光的此消彼长代替单调的"夜到昼"切换：前面的屏青光强，越往后琥珀光越强。

实现方式：给每个深色屏加一个 `::before` 伪元素，铺满整屏，`pointer-events: none`，放在内容下面。用一到两个 `radial-gradient` 做光斑，颜色是 `--ai` 和 `--human`，透明度见下表。光斑要大而柔，半径约为屏宽的 40%–60%，不能看出边缘。

| 屏 | 青光（位置，透明度） | 琥珀光（位置，透明度） | 含义 |
| --- | --- | --- | --- |
| 第1屏 开头 | 右下，0.22 | 无 | 深夜只剩屏幕的光（和插图叠加） |
| 第2屏 热词 | 右上（AI人格卡后），0.12 | 左上（活人感卡后），0.12 | 两个词，两种光 |
| 第3屏 现象 | 右上，0.18 | 无 | |
| 第4屏 本质 | 右侧（镜像图右半），0.14 | 左侧（镜像图左半），0.12 | 左边是人，右边是AI |
| 第5屏 两面 | 右侧，0.16 | 左下，0.06 | |
| 第6屏 度 | 右上，0.12 | 左下，0.12 | 两种光势均力敌 |
| 第7屏 能否代替 | 右下，0.08 | 左上，0.16 | 琥珀光开始占上风 |
| 第8屏 原理 | 关系图里"AI"节点附近，0.08 | 关系图里"我"节点附近，0.20 | 和插图叠加 |
| 第9屏 同学的声音 | 词云右侧"AI"一团后，0.12 | 词云左侧"人"一团后，0.16 | 和词云左右分色对应 |

浅色屏（第10–12屏）不加光斑，由插图和纸色完成。

### 2.3 近景：章节大字

每一层的第一屏，在版心右下角放一个超大的中文序号：

| 屏 | 字 |
| --- | --- |
| 第3屏 `#layer1` | 一 |
| 第4屏 `#layer2` | 二 |
| 第5屏 `#layer3` | 三 |
| 第10屏 `#layer4` | 四 |

- 宋体，字号约 `42vh`，行高 1；
- 颜色为当前屏正文色，不透明度 0.05（浅色屏 0.06）；
- 右下角，可以有一部分超出屏幕被裁掉；
- 放在内容下面，`pointer-events: none`，不能遮挡图表的鼠标交互；
- `aria-hidden="true"`。

### 2.4 可选：极淡的颗粒感

如果加了以后画面更好看，可以在深色屏上叠一层极淡的颗粒噪点：用内联 SVG `feTurbulence` 生成 data URI，不透明度不高于 0.04。如果影响性能或看起来脏，就不要加。

### 2.5 不要做的

- 不要把插图放在图表正后方，第8屏除外，而且第8屏要非常淡；
- 不要给插图加滤镜动画、视差、模糊动画；
- 不要新增颜色，光斑只用 `--ai` 和 `--human`；
- 不要改字体、文字和数据。
