# 任务说明：网页改版（问卷数据版）

## 0. 背景与目标

这是《马克思主义基本原理》课程"虚拟实践作品大赛"的参赛网页。主题是大学生用AI聊天、倾诉的现象，用马克思主义原理分析"AI搭子能不能代替朋友"。

仓库里是已经完成的草稿：`index.html`、`data/data.js`、`js/echarts.min.js`。草稿用的是示例数据，现在问卷已经回收（有效问卷23份）。

本次任务：

1. 换入真实数据，并调整页面结构（第3、4节）；
2. 按"三种字迹"的视觉方向重做展示和排版（第2节）；
3. 新增可点击的原话词云（第5节）；
4. 整理成可以直接用 GitHub Pages 展示的静态站点（第6节）。

范围：只做电脑端（1366×768 到 1920×1080），不加音效。现有的翻页方式和动画节奏保留。重点是**展示和排版**。

## 2. 视觉方向：「三种字迹」

### 2.1 从内容推导出的风格

作品里有三种"声音"，每种声音用一种字迹和一种颜色来写：

| 声音 | 在作品里是谁 | 字迹 | 颜色 | 推导 |
| --- | --- | --- | --- | --- |
| 经典 | 马克思原文、原理、论述 | 宋体（印刷体） | 朱色，只用于原理和原文 | 读经典时，有在页边用朱笔做批注的传统。原理以"页边朱批"的形式出现 |
| 人 | 朋友、同学的原话、"我" | 楷体（手写体） | 琥珀色（灯光） | 手写有温度、不完美，对应"活人感" |
| AI | AI的回复、AI相关的数据 | 黑体（屏幕字） | 石青色（月光、屏幕光） | 屏幕上的字精确、均匀，对应"AI人格" |

整体叙事沿用草稿：背景从**深夜**（深夜找AI倾诉）逐屏变亮，到第四层转为**白天**（走向真人交往）。

核心图形是**社会关系网络**：人与人之间是双向的实线，人与AI之间是单向的虚线。它直接来自"人的本质是一切社会关系的总和"，放在第8屏，是全片唯一的重点插图。

调查数据像书里的插图一样处理：图表编号（图1、图2……）、细线条、克制的颜色、学术式图注。

想要的气质是**一本在夜里翻开的书**：安静、严肃、有温度，有文化感，但不沉重。

### 2.3 字体

三套字体栈：

```
--song: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif;
--kai:  "LXGW WenKai", "Kaiti SC", "STKaiti", "KaiTi", "BiauKai", serif;
--hei:  "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Noto Sans CJK SC", system-ui, sans-serif;
```

| 字体 | 用在 |
| --- | --- |
| 宋（`--song`） | 标题、正文段落、马克思原文、目录、层次标记、页边朱批、图注、大数字 |
| 楷（`--kai`） | 同学原话、开头和结尾聊天里"我"的消息、"活人感"卡片、关系图里人的节点、词云里"人"一侧的词 |
| 黑（`--hei`） | AI的消息气泡、"AI人格"卡片、词云里"AI"一侧的词、图表内的文字和数字、提示框 |

- 设置 `font-synthesis: none`，避免宋体在没有粗体时被伪加粗。
- 标题字重 600，正文 400。

**可选：自托管字体（推荐，能联网时做）**

为了让评委电脑（多为 Windows）上的标题和原话显示一致，可以把字体放进 `fonts/`：

- 标题：`@fontsource/noto-serif-sc` 的 600 字重，按 unicode-range 分片的 woff2；
- 原话：`lxgw-wenkai-webfont`（霞鹜文楷）的 Regular。

只复制需要的字重，附上字体的 OFL 许可证，用本地相对路径引用。如果环境不能联网，就跳过这一步，只用上面的系统字体栈。不要从 CDN 引用字体。

### 2.5 排版

- **版心**：最大宽度 1200px，居中。版心左侧留 64px 的"页边"，用来放竖排朱批。
- **层次标记**：每屏左上角，比如"第二层　本质"，宋体 14px，次要文字色，字距 0.1em。不要全大写，不要用"·"串联多个信息。
- **页边朱批**：只出现在有原理的屏（第4、5、6、8屏）。竖排（`writing-mode: vertical-rl`），宋体 15px，朱色，字距 0.25em，右侧一条 1px 朱色细线，顶部和 h2 对齐。草稿里正文中的 `.principle` 引线样式要去掉，避免重复。
- **栏宽**：两栏 5:7（同草稿），第8屏改为 6:6。
- **大数字格式**：写成"21/23"，其中"/23"的字号是主数字的 40%，后面跟一个"人"字；百分比放在下方的说明文字里，例如"人用过AI聊天、倾诉或寻求安慰（91%）"。
- **图注**：全站图表按出现顺序编号"图1""图2"……；格式为"图3　通常在什么情况下找AI聊天（第6题，多选，用过AI倾诉的21人作答）"。
- **同学原话**：楷体，左侧一条 2px 琥珀色竖线，前面可以有一行次要文字的引导（如"一位同学写道："）。不显示问卷序号。
- **圆角**：聊天气泡和热词卡片保留圆角；图表条形、原话面板、分隔线用直角。
- **适配**：每一屏在 1366×768 下完整显示、没有屏内滚动；在 1920×1080 下版心居中，不要拉伸。

### 2.6 图表样式

- 继续使用 ECharts，SVG 渲染，本地文件 `js/echarts.min.js`。
- 条形高度 10px，直角；不要灰色底轨、阴影或渐变。
- 去掉坐标轴和网格线，只保留类别名，必要时加一条基线。
- 横条图的条末标注"13人（62%）"；分段条的段内标注"7人"，宽度不够就不标，改由图例和提示框提供。
- 提示框（tooltip）显示"选项：X人，占Y%（n=…）"。
- 颜色按含义分配：与"人"有关的选项用琥珀，与"AI"有关的用石青，中性选项用灰；同一类不同程度用同一色相的深浅。每个图的具体配色见第3节。

### 2.7 动效

- 保留草稿已有的：逐屏吸附、开头消息逐条出现、图表进入视口时生长、镜像条形生长。
- 新增一处：第8屏的关系示意图，进入该屏时线条依次画出（约 1.2 秒，只播放一次）。
- 词云选中切换的过渡 200ms 左右。
- 开启 `prefers-reduced-motion` 时，所有动画直接显示最终状态。

### 2.8 不要做的

- 红色大标语、五角星、旗帜等党建海报元素；
- 赛博朋克、霓虹、发光的"科技感"；
- 卡通插画、表情包；
- 纸张纹理、牛皮纸等贴图；
- 卡片阴影堆叠、装饰性渐变色块；
- 所有文字居中排版。

### 5.1 原则

- **不用自动分词。** 关键词由小组从11条原话中整理，见下表。
